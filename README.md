## What it does

`main.py` writes one line — a hilarious autocorrect fail — to
`/output/entry.txt`. The program validates the line against the
competition gate before writing (a single line, 1–199 characters, not
only whitespace), then reads the file back and checks it holds exactly
what was written.

## The line

> Told my teacher I can't come to class, I have explosive diarrhea —
> autocorrect changed 'diarrhea' to 'diploma' and now she thinks I have
> an explosive diploma

## Run it

```bash
python3 main.py
```
